# Decisions

Decisions made from 24 Nov 2026 onward. Earlier decisions are recorded in [PRD.md §4](./PRD.md#4-decisions-log). Newest at the bottom.

| Date | Decision | Reason |
| --- | --- | --- |
| 2026-11-24 | **One Judge0 submission per Run/Submit.** A hidden harness runs all cases in one process, times each case itself and prints one flushed JSON line per case, and stops cleanly when the overall time budget runs out. Cases left over are reported as `not_run`, not lost. Overall limit = per-case limit × case count, capped per problem (`max_total_ms`) and by the Judge0 plan's max wall time. Expected outputs stay in the worker. | Judge0 on RapidAPI bills and rate-limits per submission. One submission per test case would cost 12+ calls per Submit. |
| 2026-11-24 | **`supabase/` stays at the repo root**, and `supabase/migrations/` stays the source of truth. The monorepo uses **npm workspaces**, not pnpm. `packages/db` holds generated types and query helpers only. | The Supabase CLI and production's migration ledger (50 applied migrations) expect `supabase/migrations/`. npm keeps the existing lockfile and tooling. |
| 2026-11-24 | **Submissions are private and leak-safe.** For hidden cases the worker writes only case number, verdict and runtime, never input or output. An owner-only `SELECT` RLS policy (`user_id = auth.uid()`) on `submissions` is what makes Realtime subscriptions safe. | Realtime pushes whatever row the subscriber can read. Without these rules, hidden tests or other users' code could reach the browser. |
| 2026-11-24 | **Code font is Geist Mono everywhere**, including code blocks (DESIGN.md §5). | §2.2 and §10 limit families to Instrument Serif, Geist and Geist Mono. §5's JetBrains Mono contradicted that. |
| 2026-11-24 | **ESLint lint script and CI arrive in milestone 1.** CI runs typecheck, lint, Vitest, build and `npx impeccable detect`. The detector covers new UI paths until the legacy UI is removed. | The repo had no lint script or CI. Quality gates need to exist before the new UI grows. |
| 2026-11-24 | **Launch content: playable problems are Algogym originals only.** LeetCode/GFG problems appear as metadata (source badge, company tags, "View original", "Similar Algogym problem" when linked) on the Companies and Problems pages. Adapted statements come after launch, highest company frequency first. | Lowest takedown risk at launch, and quality over volume. Company metadata still gives users the "what does X ask" value. |
| 2026-11-24 | **`docs/SYSTEM_ARCHITECTURE.md` is the architecture doc.** No separate `ARCHITECTURE.md`. | Avoids two competing architecture files. |
| 2026-11-25 | **Design tokens are prefixed `--ag-` in code** (`--ag-surface-1`, `--ag-accent`, …), with a Tailwind `ag` colour namespace (`bg-ag-surface-1`). Names otherwise match DESIGN.md §2. | The legacy shadcn theme already defines `--border`, `--accent` and `--muted` as HSL triplets, and the remaining Radix components (dialog, select, sheet) use them. The prefix lets both coexist until the legacy theme is removed. |
| 2026-11-25 | **`--text-faint` is #84848D, not #71717A.** A contrast test (`src/styles/tokens.spec.ts`) checks every text token on every surface. | #71717A measured 3.59–4.35:1, below WCAG AA's 4.5:1 for caption text. #84848D gives 4.69:1 on the lightest surface (`--surface-3`). |
| 2026-11-25 | **ESLint baseline for legacy code.** 46 legacy files that failed lint when it was introduced get those rules as warnings, listed in `eslint.config.mjs`. New code gets the full rule set. | Fixing code that M2 deletes is wasted work. The list only shrinks. |
| 2026-11-25 | **zod bumped from 3.23 to 3.25 (still the v3 API).** | `eslint-plugin-react-hooks` 7 needs `zod/v4/core`, which only zod ≥ 3.25 ships. |
| 2026-11-25 | **No gradient text.** Headings use solid `--text` (#F5F5F7). The `.ag-heading-gradient` class and its Impeccable exception are removed (DESIGN.md §2.2, §10). | Impeccable flags gradient text as an AI tell. A solid heading colour keeps the detector clean without exceptions. |
| 2026-11-25 | **UI font is Hanken Grotesk** (Google Fonts, OFL) instead of Geist. Geist Mono stays for code. CSS variable `--font-ui`, Tailwind class `font-ui`. | DESIGN.md said Geist would pass Impeccable's overused-font check, but the live-page scan flags Geist, and it flagged Instrument Sans (the first replacement tried) as well. Hanken Grotesk was next in the agreed order and passes with 0 findings. Geist Mono wasn't flagged. |
| 2026-11-25 | **`/_design` preview pages return 404 when `VERCEL_ENV === "production"`** (checked in each page, not a layout), and are available in local dev and Vercel previews. They stay on the legacy AuthGate allow-list. | Internal tooling shouldn't ship to production. Next's generated route types reject a layout in the `%5Fdesign` folder. Without the allow-list entry, the old sign-in dialog would cover the page in preview and the 404 in production. |
| 2026-11-25 | **Production stays on the legacy app until launch.** Branch `release/legacy` (cut from bba0d27) is Vercel's Production Branch. Every milestone merges to `main` as soon as it's done, and `main` deploys previews only. At launch (M20) the Production Branch switches back to `main`. | Real users keep the features they use while the new product is built. `main` can drop legacy code without a production gap or feature flags. |
| 2026-11-25 | **Additive-only migrations until launch.** No rename, move, drop or stricter constraint on existing tables. Archiving legacy tables to the `legacy` schema moves from M4 to the M20 launch cutover, along with the entitlement backfill and the Razorpay webhook switch. | The legacy app on `release/legacy` shares the production database. Any non-additive change would break it. |
| 2026-11-25 | **Starter code and harnesses are generated from `meta.json`'s typed signature** (M5), with optional per-language `starter/` and `harness/` overrides. Tests are JSON: `NN.in` holds the argument list, `NN.out` the return value. | Removes 8 hand-written files per problem (about 480 for launch) and per-problem JSON parsing in C++ and Java. One generator can be tested once for every signature type. |
| 2026-11-25 | **M2 scope:** besides the BUILD_GUIDE list, `/dashboard`, `/workspace`, `/notes`, `/profile`, `/profile/card` and `/u/[username]` are removed. `/settings` stays without platform connections. Removed URLs and the post-sign-in landing go to `/problems` until M13 switches them to `/roadmap`. `/` becomes a holding page built from the M1 shell. | These screens are built on ratings, Chakra, sheets or provider sync. `/roadmap` doesn't exist until M13, and redirecting there earlier would 404. |
| 2026-11-25 | **M2 keeps the legacy endpoints that surviving pages still call**: `/api/onboarding` (GET is the account-state endpoint for AuthGate, layout, billing and Interview Prep), the `/problems` catalog and detail APIs (`providers`, `problem`, `tracker`, `sync`, `study`) until M8/M9, and `coin-exchange` until the M17 pricing rewrite. The sign-in dialog always lands on `/problems` and no longer reads a `next` query parameter. | Removing them would break pages M2 must leave working. The only `next` target was the removed society-invite flow, and dropping it removes an open-redirect surface. |
| 2026-11-25 | **Monorepo layout (M3):** the Next.js app is the npm workspace `apps/web` (`@algogym/web`); `supabase/`, `scripts/`, `content/`, `data/`, `docs/` stay at the root. Root scripts forward to the workspace. ESLint (one config, `content/**` ignored) and the Impeccable check run from the root. Vercel Root Directory is `apps/web`. | Matches SYSTEM_ARCHITECTURE.md §3 and leaves room for `apps/engine` (M11). One root lockfile and one install. |
| 2026-11-25 | **Local env files stay at the repo root.** `apps/web/next.config.ts` reads them with Node's `util.parseEnv`, in Next's precedence order, without overriding variables already set. | Scripts and the app share one `.env.local`. `@next/env`'s `loadEnvConfig` can't load a second directory: it returns its cached `apps/web` result. Vercel injects env vars, so nothing changes there. |
| 2026-11-25 | **Shell navigation links only to routes that exist.** Each milestone adds its own link. | Linking to unbuilt routes showed 404s, and Next's link prefetching left those requests open, so pages never reached network idle (the Impeccable timeout on `/`). |
| 2026-11-25 | **Lesson diagrams are SVG**, generated from DESIGN.md tokens (`scripts/content/build-figures-c2.mjs`), instead of WebP. WebP stays for screenshots and photos. | Line-and-text diagrams stay sharp at any size, are 4–6 KB each, and can be edited and regenerated in code. |
| 2026-11-25 | **Top-30 companies for M7** are ranked by distinct questions in liquidslr's "All" list (`data/companies/top-30.json`, from source commit `2b71796`). Only names, slugs and per-timeframe counts are stored. | A transparent, reproducible ranking (`scripts/data/top-companies.mjs`). The source has no license, so nothing beyond metadata is kept. |
| 2026-11-26 | **Workspace uses floating panels** modelled on the flux.rq3.workers.dev editor (DESIGN.md §6.6, M9 "done when"): 12 px gaps, 16 px-radius `--surface-1` cards with a 1 px `--border`, and one floating top bar. Run is an off-white pill with a black play icon and Submit is the emerald primary. Ctrl+Enter runs and Ctrl+Shift+Enter submits. Three panels at ≥ 1280 px. Output · Input · Tests dock under the editor at 768–1279 px (the brief gave 1024–1279; 768–1023 follows the same layout). Tabs "Problem · Code · Result" below 768 px. Monochrome, with emerald only for Submit, passed cases and focus, so Monaco's selection and cursor are neutral, not emerald. Presence avatars and Share are kept for Rooms (v1.1). Replaces the earlier 45/55 split-pane spec. | Product owner's direction. Floating cards read calmer than edge-to-edge panes, and a single accent keeps Submit the one obvious action. |
