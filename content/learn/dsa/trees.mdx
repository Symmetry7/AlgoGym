## The idea

A **binary tree** is a set of nodes where each node has at most two children and every node except the root has exactly one parent. Algogym problems store one as arrays: `left[i]` and `right[i]` are node `i`'s children, with `-1` for none.

Nearly every tree question is a **walk** with something carried along:

- **Breadth-first (BFS):** visit the tree level by level with a queue. Use it for depths, level totals and "nearest" questions.
- **Depth-first (DFS):** follow one branch to the bottom before backing up. Use it for path questions and subtree answers (sizes, heights, mirrors).

## Intuition

<Figure src="/learn/dsa/trees/levels.svg" alt="A binary tree with root 8, children 3 and 10, and grandchildren 1, 6 and 14, grouped into three dashed bands labelled level 0, level 1 and level 2." />

Think of a family tree. BFS reads it generation by generation: grandparents, then all their children, then all the grandchildren. DFS follows one line of descent to the youngest member, then comes back up to try the next branch.

## Worked example

*Family Tree Depth* with `left = [1, 3, -1, -1, -1]` and `right = [2, 4, -1, -1, -1]`, root `0`.

Start with the level `[0]` and count 1. Its children make the level `[1, 2]`: count 2. Node 1 has children 3 and 4 and node 2 has none, so the next level is `[3, 4]`: count 3. Nodes 3 and 4 have no children, so the walk stops. The depth is **3**, the number of levels, found without a single recursive call.

## Code

<CodeTabs>

```js
// Values of each level, top to bottom.
function levels(values, left, right, root) {
  const out = [];
  let level = [root];
  while (level.length) {
    out.push(level.map((v) => values[v]));
    const next = [];
    for (const v of level) {
      if (left[v] !== -1) next.push(left[v]);
      if (right[v] !== -1) next.push(right[v]);
    }
    level = next;
  }
  return out;
}
```

```python
def levels(values: list[int], left: list[int], right: list[int], root: int) -> list[list[int]]:
    out, level = [], [root]
    while level:
        out.append([values[v] for v in level])
        level = [c for v in level for c in (left[v], right[v]) if c != -1]
    return out
```

```cpp
vector<vector<int>> levels(const vector<int>& values, const vector<int>& left, const vector<int>& right, int root) {
    vector<vector<int>> out;
    vector<int> level = {root}, next;
    while (!level.empty()) {
        out.emplace_back();
        next.clear();
        for (int v : level) {
            out.back().push_back(values[v]);
            if (left[v] != -1) next.push_back(left[v]);
            if (right[v] != -1) next.push_back(right[v]);
        }
        level.swap(next);
    }
    return out;
}
```

```java
List<List<Integer>> levels(int[] values, int[] left, int[] right, int root) {
    List<List<Integer>> out = new ArrayList<>();
    List<Integer> level = List.of(root);
    while (!level.isEmpty()) {
        List<Integer> row = new ArrayList<>(), next = new ArrayList<>();
        for (int v : level) {
            row.add(values[v]);
            if (left[v] != -1) next.add(left[v]);
            if (right[v] != -1) next.add(right[v]);
        }
        out.add(row);
        level = next;
    }
    return out;
}
```

## Complexity

| | |
| --- | --- |
| Time | O(n): every node enters and leaves the walk once |
| Space | O(width) for BFS, O(height) for DFS |

## Common mistakes

<Callout>

- **Recursing on a deep tree.** A chain of 10^5 nodes means 10^5 nested calls. Use an explicit queue or stack.
- **Mixing up depth and edges.** A single node has depth 1 but zero edges. Read which one the problem asks for.
- **Comparing the wrong pairs.** For mirrors, pair `left` with `right`; for identical trees, pair `left` with `left`.

</Callout>
