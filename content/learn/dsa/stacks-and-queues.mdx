## The idea

A **stack** is a pile: you add and remove at the top, so the last thing in is the first out. Use it whenever the newest unfinished item matters most, like the innermost open bracket or the days still waiting for warmer weather.

A **queue** is a line: you join at the back and leave from the front, so the first in is the first out. Use it when order of arrival matters, like students waiting for tiffins or cells waiting to be explored in breadth-first search.

Both do every operation in O(1). An array with a top index makes a stack. A queue needs a head index, or a ring buffer, so that removing from the front doesn't shift every element.

## Intuition

<Figure src="/learn/dsa/stacks-and-queues/stack-queue.svg" alt="Left: a stack of three plates where items are pushed and popped at the top. Right: a queue of four numbers where items join at the back and leave from the front." />

Plates in a mess are a stack: you take the top one, the one put there last. The ticket counter at a railway station is a queue: whoever came first is served first.

A **monotonic stack** is a stack you keep in sorted order by popping everything that the new item "beats" before pushing it. Each pop is the moment a waiting item gets its answer.

## Worked example

*Bracket Log* checks `{[()()]}`. Push `{`, `[`, `(`. The first `)` matches the top `(`: pop. Push `(` again, and the next `)` pops it. Now `]` meets `[` on top: pop. Finally `}` meets `{`: pop. Nothing failed and the stack is empty, so the log is **balanced**.

For `([)]`, the `)` arrives while `[` is on top, so the check fails straight away, even though each kind appears twice.

## Code

<CodeTabs>

```js
function isBalanced(log) {
  const partner = { ")": "(", "]": "[", "}": "{" };
  const stack = [];
  for (const c of log) {
    if (c === "(" || c === "[" || c === "{") stack.push(c);
    else if (stack.pop() !== partner[c]) return false;
  }
  return stack.length === 0;
}
```

```python
def is_balanced(log: str) -> bool:
    partner = {")": "(", "]": "[", "}": "{"}
    stack = []
    for c in log:
        if c in "([{":
            stack.append(c)
        elif not stack or stack.pop() != partner[c]:
            return False
    return not stack
```

```cpp
bool isBalanced(const string& log) {
    vector<char> stack;
    for (char c : log) {
        if (c == '(' || c == '[' || c == '{') { stack.push_back(c); continue; }
        char want = c == ')' ? '(' : c == ']' ? '[' : '{';
        if (stack.empty() || stack.back() != want) return false;
        stack.pop_back();
    }
    return stack.empty();
}
```

```java
boolean isBalanced(String log) {
    char[] stack = new char[log.length()];
    int top = 0;
    for (char c : log.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') { stack[top++] = c; continue; }
        char want = c == ')' ? '(' : c == ']' ? '[' : '{';
        if (top == 0 || stack[top - 1] != want) return false;
        top--;
    }
    return top == 0;
}
```

## Complexity

| | |
| --- | --- |
| Time | O(1) per push, pop, enqueue or dequeue; O(n) for a full scan, monotonic stacks included |
| Space | O(n) in the worst case |

## Common mistakes

<Callout>

- **Popping an empty stack.** Check before you pop: a log that starts with `)` must fail, not crash.
- **Forgetting what is left at the end.** Items still on the stack are unmatched brackets, or days with no warmer day.
- **Removing from the front of an array as a queue.** `shift()` in JavaScript and `list.pop(0)` in Python move every element. Keep a head index, or use `collections.deque` or `ArrayDeque`.

</Callout>
