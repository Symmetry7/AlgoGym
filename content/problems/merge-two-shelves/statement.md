A library is combining two shelves. Each shelf's books are already ordered by catalogue number, smallest first: `left` and `right` are both sorted in non-decreasing order.

Return one list with every catalogue number from both shelves, sorted in non-decreasing order.

## Constraints

- `0 ≤ left.length, right.length ≤ 10^5`
- `−10^9 ≤ left[i], right[j] ≤ 10^9`
- Both lists are sorted in non-decreasing order.
