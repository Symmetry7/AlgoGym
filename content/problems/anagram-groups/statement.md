A word-game server wants to know how many distinct letter sets its players used. Two words belong to the same **group** when one is a rearrangement of the other's letters, using every letter the same number of times.

Return the number of groups among `words`. Repeated words belong to the same group.

## Constraints

- `1 ≤ words.length ≤ 5 × 10^4`
- `1 ≤ words[i].length ≤ 12`
- `words[i]` contains only lowercase letters.
