You will read a book's chapters in order; chapter `i` has `pages[i]` pages. Each day you read one or more whole chapters, continuing where you stopped, and you must finish within `days` days.

Return the smallest possible value of the most pages you read on any single day.

## Constraints

- `1 ≤ pages.length ≤ 10^5`
- `1 ≤ pages[i] ≤ 10^4`
- `1 ≤ days ≤ pages.length`
