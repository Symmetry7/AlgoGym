A crowdfunding page lists each day's donations in order; every `donations[i]` is positive. The team wants the shortest run of consecutive days that together raised at least `goal`.

Return the length of that run, or `0` if even all days together fall short.

## Constraints

- `1 ≤ donations.length ≤ 10^5`
- `1 ≤ donations[i] ≤ 10^4`
- `1 ≤ goal ≤ 10^9`
