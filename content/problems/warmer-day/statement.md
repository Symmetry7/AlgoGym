A weather station in Shimla logs one maximum temperature per day. For planning a trek, you want to know how long each day has to wait for warmer weather.

Given the daily temperatures `temps`, return an array where entry `i` is the number of days after day `i` until a strictly warmer day. If no later day is warmer, the entry is `0`.

## Constraints

- `1 ≤ temps.length ≤ 10^5`
- `−50 ≤ temps[i] ≤ 60`
